# v0.3.10 Release Notes

This release makes empty Excel export attempts clear and non-technical.

## Improvements

- **Actionable warning**: If the selected scope contains no tables, the plugin now asks the user to generate a table first.
- **No false error**: The expected no-table scenario no longer raises an HTTP 400 error and is displayed as a warning instead.
- **Localized guidance**: The warning is available in English, Chinese, and Russian based on the user's language.
